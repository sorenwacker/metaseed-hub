Remove content

Remove a dataset or published specification from any account, for content created or published by mistake. Removal is by identifier — the UUID in the item's URL — because this dashboard reports aggregated counts and does not list other people's content.

The result names the item and the account that owns it, so a mistyped identifier is visible immediately. Nothing is erased, and Restore undoes a removal using the same identifier.
