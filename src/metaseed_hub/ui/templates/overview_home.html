Getting set up, and where each thing lives.

  1. Create a dataset

    Datasets in the top bar, then + New Dataset. Pick a standard — MIAPPE, ISA, Darwin Core, ENA — or import an existing record from ENA, PRIDE, MetaboLights or a BrAPI server instead of starting empty.

    New dataset

  2. Fill it in, and see what is missing

    Open a dataset and use the entity tree on the left. Every change is checked against the specification, so the panel tells you which required fields are still empty rather than leaving you to find out at submission. Use Export when it is complete.

  3. Build your own specification

    Builder in the top bar, then New Specification, when no existing standard fits your work. Add entities and fields, validate as you design, and Publish to share it with everyone here. Publishing is reversible — Unpublish brings it back as a private draft.

    Open Builder

  4. Compare standards before committing

    Explorer shows any specification's entities, how they nest and what each field means — including ones other people published.

    Open Explorer

  5. Share with colleagues

    Open a dataset and use the Sharing tab in the right panel. Add someone by the email on their profile and choose Owner, Curator or Viewer. The Comments tab keeps the discussion on the record itself.

  6. Connect an AI assistant

    Create an API key on your profile — the avatar at the top right, then Access tokens. It is shown once, so copy it then. Register this hub with your client:

    Endpoint https://metaseed.ewi.tudelft.nl/hub/mcp
    Transport http (streamable HTTP)
    Authentication Authorization: Bearer msh_your_key

    Any client that speaks the Model Context Protocol can use those three details. For Claude Code: 

    claude mcp add --transport http --scope user metaseed-hub \
  https://metaseed.ewi.tudelft.nl/hub/mcp \
  --header "Authorization: Bearer msh_your_key"

    The key acts as you and reaches only your own datasets. Every change it makes is versioned and restorable, and it cannot publish a specification on your behalf.
