# Projects

Projects contain metadata entities organized according to a profile specification.

## Creating a Project

1. Open a workspace
2. Click **New Project**
3. Enter a project name
4. Select a profile (MIAPPE, ISA, DiSSCo, Darwin Core)
5. Optionally load example data
6. Click **Create**

## Profiles

| Profile | Description |
|---------|-------------|
| MIAPPE | Minimum Information About Plant Phenotyping Experiments |
| ISA | Investigation-Study-Assay for life sciences |
| DiSSCo | Digital Specimen standard for natural history collections |
| Darwin Core | Biodiversity occurrence data |

## Working with Entities

### Entity Tree

The left sidebar shows all entities in a hierarchical tree. Click an entity to edit it.

### Creating Entities

1. Click **+ New** in the entity tree header
2. Select the entity type
3. Fill in required fields (marked with *)
4. Click **Save**

### Editing Entities

1. Click an entity in the tree
2. Modify fields in the form
3. Click **Save**

### Deleting Entities

Click the delete button (x) next to an entity in the tree.
